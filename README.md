# 🎬 Movie Recommender App

Простое десктопное приложение (с возможностью комплияции под мобильные устройства) на Python с использованием Kivy для поиска фильмов, хранения личной библиотеки и получения рекомендаций на основе предпочтений пользователя.

---

## 📦 Технологии
- Python 3.13
- Kivy
- NumPy
- Pandas
- Scikit-learn

---

## 🚀 Возможности

### 🔍 Поиск фильмов
- Предзагрузка датасета OMDb
- Поиск по названию через OMDb API  
- Отображение:
  - постера  
  - названия и года  
  - описания  

---

### 🧠 Поиск по смыслу (Semantic Search)
- Ввод произвольного описания (например: *"dark sci-fi about space and AI"*)
- Поиск похожих фильмов через TF-IDF
- Работает локально

---

### ⭐ Рекомендации
- Персональные рекомендации на основе:
  - оценок пользователя  
  - сохраненных фильмов  

Алгоритм:
- TF-IDF + cosine similarity  
- Усреднение вектора понравившихся фильмов  

---

### 📚 Библиотека пользователя
- Сохранение фильмов
- Отображение:
  - постера
  - жанра  
  - оценки  
  - краткого описания  

---

### 📝 Оценки
- Возможность поставить рейтинг (0 – 5.0)
- Используется для рекомендаций

---

## 🖥️ Интерфейс

Приложение состоит из 3 экранов:

### 1. Search Screen
- Поиск по названию  
- Поиск по смыслу  
- Результаты поиска  
- Рекомендации  

### 2. Details Screen
- Полная информация о фильме  
- Постер  
- Добавление в библиотеку  
- Оценка  

### 3. Library Screen
- Список сохранённых фильмов  
- UI в стиле карточек
